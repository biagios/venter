# Security Policy
Please read this document if you have found a security vulnerability with Venter.

## Supported Versions

Only the most recent version is supported with security updates. All previous versions of the bot will **not** receive any updates.

## Reporting a Vulnerability

When reporting a security vulnerability please get in touch with any person who maintains the bot. Once a vulnerability report has been submitted, it will be evaluated. In evaluation depending on the severity of the report you *may* be rewarded accordingly at will by contributors.
